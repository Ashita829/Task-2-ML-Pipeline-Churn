# Task-2-ML-Pipeline-Churn
# Customer Churn Prediction using Scikit-learn Pipeline

## Objective
Build an end-to-end machine learning pipeline to predict customer churn using the Telco Churn dataset.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Steps Performed
- Data preprocessing
- Missing value handling
- Feature scaling
- One-hot encoding
- Pipeline creation
- Model training using Random Forest
- Hyperparameter tuning using GridSearchCV
- Model evaluation

## Results
- Best Accuracy: 80.48%
- Best Parameters:
  - max_depth = 10
  - n_estimators = 50

## Output
The trained pipeline was exported as:
`churn_pipeline.pkl`
